# 📚 MacEng Practice

Practice problems for McMaster engineering courses: instant answer checking, targeted remediation, and optional cross-device progress.

<https://www.macengpractice.com>

## Features

- 🎯 **Answer checking** - tolerance-based grading, with unit validation included.
- 📈 **Targeted remediation & spaced repetition** - each user has a unique skill profile for every question type. You are served questions targeting your weakest skill areas, helping you build a more well-rounded academic foundation.
- 🔐 **Accounts** - optional and passwordless: a magic link to your inbox keeps your progress on every device.

Built with HTML, CSS, JavaScript, and KaTeX for math rendering.
